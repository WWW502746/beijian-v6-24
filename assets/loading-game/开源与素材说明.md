# 叠石成拓：素材与许可

此加载游戏使用离线预渲染的石碑切片、宣纸和墨面图像，以浏览器画布绘制。碑体及碑文为数字创作，不是文物实测扫描。

石碑、纸墨与背景图由本项目制作。画面资源包含在 render-data.js、paper-data.js 和两幅碑廊背景图内，不依赖外部图片或字体服务。

操作音效采用 Frank Force 的 ZzFX Micro 1.4.0（MIT），原始许可证见 vendor/ZZFX-LICENSE.txt，固定源码版本见 vendor/ZZFX-SOURCE.txt。实际反馈代码 feedback.js 保留 MIT 声明，声音默认关闭，首次开启才创建音频上下文。

本次接入保留已确认的 V11 玩法、石碑材质、逐字完美反馈和扬尘，仅对接网站真实加载进度及进入回调。
